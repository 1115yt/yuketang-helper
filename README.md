# 雨课堂学习辅助脚本

当前版本：4.0.8

本项目基于 [Niuwh/yuketang-jiaoben](https://github.com/Niuwh/yuketang-jiaoben) 修改维护，主要差异见 [CHANGELOG.md](CHANGELOG.md)。

## 上游项目

上游仓库由 GitHub 用户 Niuwh 发布，原用户脚本署名作者为“风之子”，并有社区贡献者参与。该项目是面向雨课堂的专用脚本，也欢迎社区贡献。本仓库由 1115yt 基于上游代码继续维护，感谢原作者和所有贡献者。

## 本修改版新增与改进

以下按使用场景列出本地版本相对上游的主要增量，便于快速了解功能；本人上课时遇到的问题及逐项处理记录见 [CHANGELOG.md](CHANGELOG.md)。

### 视频播放与完成度

- 倍速和静音优先通过播放器原生控件同步，并核对控件状态和媒体实际状态；无法确认时停止，不只根据脚本设置值报告成功。
- 视频结束后等待课程页确认完成，再进入下一项；已完成内容可跳过，页面状态不明确时保留当前位置。
- 可根据观看日志定位未覆盖区间并补播缺失部分。补播逻辑已做本地测试，尚未遇到真实缺口案例验证。

### 手动启动与课程导航

- 页面打开或刷新后等待用户手动点击“开始刷课”，不自动开始。
- 学习空间内切换到同课程页面时，可在校验后接续一次；普通刷新、停止后或标记过期时不接续。
- 等待异步目录加载完成后重新读取项目，定位首个未完成项，避免目录只展开而任务没有启动或需要重复点击。
- 处理 V2、Pro、学习空间等页面；对图文项目按页面状态确认已读。

### AI 作业与讨论

- 已提交的题目在请求 AI 前跳过；识别禁用的“已提交”按钮，以及当前题目的得分和正确答案反馈。从讨论页实际单元控制栏读取“已发言”状态并跳过，填写前和发送前再次检查状态。

- 作业可选择 OCR 识别或当前题目截图识别；截图会显示在面板供核对，支持识图的题目截图模式需要使用支持图片输入的模型。
- 对填空、选择和判断题检查答案结构、数量及选项范围；答案为空、格式错误或无法判断时停止，不填写、不选择、不提交。
- 可设置题前和提交前等待，并选择自动提交或手动提交。建议将“每题开始前等待”设置为3秒以上，以降低操作过快触发验证码的概率，但不能保证完全避免验证码。已提交题目的跳过也遵守此设置，最少等待3秒；切题前和跳过等待期间检查验证码，检测到验证即停止。
- 可启用二次核对；两次请求遵循所选 OCR／截图模式，分歧时在面板展示两份答案并等待人工处理。同一模型复核不保证正确。
- 按平台明确的正确、错误反馈统计本轮作业结果；未判分题目不计入正确率。
- 修复 V2、Pro、学习空间讨论入口。开启自动回复后，会把页面已有回答复制到主发表框并发送；平台已读／已完成的项目直接跳过，不重复发表评论；仅未完成项目按自动回复开关处理。支持懒加载后的回答读取，发送后检查新增评论或成功提示；关闭时跳过，不能确认成功时停止且不盲目重发。

### AI 配置、日志与密钥

- 常见 API 基础地址可自动补齐接口路径；连接检测、模型列表和答题请求使用一致的地址处理规则。
- 运行日志显示处理阶段、AI 等待时间和可观测的 HTTP 状态，停止任务时可取消等待中的请求。
- 日志默认保留 30 分钟、最多 300 条，可从面板导出；分享前请检查题目、答案和个人信息。
- 点击“日志 / 诊断”打开独立导出窗口。普通日志保留现有内容；诊断包额外收集页面操作元素和播放器状态，默认不附截图，不读取表单值、页面正文、Cookie 或存储配置。可选附带最近题目截图，图片需人工检查；文件仅保存到本地，由用户自行决定是否上传，公开后可能被他人查看、复制和保存。
- API Key 保存于用户脚本隔离存储，不自动从旧版网页存储迁移；认证信息会在日志中脱敏，但发起请求时仍会发送给所配置的 AI 服务。

更新记录中的问题均来自本人上课过程中遇到或观察到的情况。当前处理不代表脚本已经完善；欢迎大家提出问题和建议，一起维护改进。

## 安装和使用

Tampermonkey 通用安装教程（第三方视频）：[B站视频](https://www.bilibili.com/video/BV1tnqrYcEZM)。本项目脚本的安装步骤见下方。

1. 安装 Tampermonkey 后，打开 [GitHub 原始脚本](https://raw.githubusercontent.com/1115yt/yuketang-helper/main/yuketang-helper.user.js)，在 Tampermonkey 安装页面确认安装。只启用一个本项目版本。
2. 刷新雨课堂课程页。进入课程目录或学习空间后，手动点击“开始刷课”；普通刷新或直接打开页面不会自动启动。
3. 点击“播放 / AI设置”配置播放速度、静音和作业选项。播放器设置优先与页面原生控件同步；平台是否记录观看完成度仍以页面和观看日志实际显示为准。

本人测试的课程使用2倍速可正常记录完成度，不保证所有课程规则一致；若完成度不增长或记录异常，请尝试1倍速观看。
4. 使用 AI 答题时，填写 API 地址、模型和 Key。常见服务可只填写 API 基础地址；自定义接口可填写完整路径。修改配置后使用“检测连接”或“获取模型列表”排查连通性。
5. 初次使用截图识题或自动提交时，先人工核对识别内容和答案。需要人工提交时，在设置中选择手动提交。

脚本已配置 GitHub 更新地址。发布新版本时会递增 `@version`；已从上述原始脚本地址安装的用户，可在 Tampermonkey 管理面板检查更新。

## AI、密钥和日志

- API Key 保存于 Tampermonkey 隔离存储，不写入用户脚本源码或网站存储。请求 AI 时，题目文字或当前题目截图以及认证信息会发送到设置的服务地址；请只使用你信任的服务商。
- @connect * 是为了允许用户自定义 API 域名。使用自建或第三方服务前，请核对目标地址及其隐私条款。
- 截图识题要求模型接口支持图片输入。OCR 与截图识题都可能误读；同一个模型进行两次核对也可能重复出错，两次答案一致不代表正确。
- 运行日志默认保留 30 分钟，最多 300 条，并可从面板导出。日志可能包含题目答案和运行状态；分享前请检查内容并删除个人信息。密钥和认证信息会脱敏，但导出的日志仍应按敏感资料处理。
- 自动提交是可配置选项。作业是否正确应以平台反馈或标准答案为准；脚本无法保证答案正确，也不能保证平台接受所有播放或提交行为。

## 实测范围

本项目各项功能均经过测试，主要流程已在本人实际使用的雨课堂页面实测。不同学校、课程、模型和播放器仍可能有差异；视频缺失区间补播尚未遇到真实缺口案例，目前仅完成本地逻辑测试。模型回答正确率以平台判分或标准答案为准，观看记录及提交结果以页面实际反馈为准。
